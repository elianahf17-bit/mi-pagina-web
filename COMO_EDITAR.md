# Cómo editar las propiedades

1. Entre a github.com, abra el repositorio y haga clic en el archivo `propiedades.json`.
2. Toque el lápiz (Edit), cambie los textos y copie un bloque `{ ... }` para agregar otra propiedad.
3. Abajo, presione "Commit changes". La página se actualiza en unos minutos.
4. Para fotos: abra la carpeta `img`, "Add file" → "Upload files", suba la foto y confirme.
5. El nombre de la foto debe ser igual al de `propiedades.json` (ej: `img/alajuela-1.jpg`).
6. Provincias válidas: San José, Alajuela, Cartago, Heredia, Guanacaste, Puntarenas, Limón.
7. Error común: falta una coma `,` entre dos propiedades `},{` (la última NO lleva coma).
8. Error común: use comillas rectas `"texto"`, no comillas curvas “así”.
9. Todo texto va entre comillas, y no borre los corchetes `[ ]` del inicio y del final.
10. Si la página queda vacía, hay un error en el archivo: deshaga el último cambio.
